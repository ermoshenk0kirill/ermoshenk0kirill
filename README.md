## Чем занимаюсь

Фронтенд для меня начинается там, где макет превращается в живую страницу: адаптивная вёрстка,
аккуратная семантика, анимации по делу, а не ради анимаций. Дальше подключается JavaScript,
и статичная картинка становится интерфейсом, который реагирует, помнит состояние и не раздражает.

Учусь на магистратуре по информационной безопасности, поэтому смотрю на код ещё и глазами того,
кто пытается его сломать. Хороший интерфейс должен быть не только красивым, но и надёжным.
